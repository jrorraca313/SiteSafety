# SiteSafety

A plain-language website trust checker. Paste a link and get a 0–100 Trust Score with a risk level and a short explanation of each check (secure connection, site age, browser protections).

CS 4002/4003 Computer Science Project, Team #2.

## Stack

Python + FastAPI, PostgreSQL, HTML/CSS/JavaScript, pytest.

## How we work

- Every change goes through a pull request; `main` only changes through merged PRs.
- CI runs the tests on every pull request.
